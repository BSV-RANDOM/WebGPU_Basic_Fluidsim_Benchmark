# WebGPU_Basic_Fluidsim_Benchmark
*Currently buggy but functional

A basic Fluid sim benchmark created in webgpu as a single stand alone HTML file. Designed to test webgl2 vs webgpu. For this reason structured like a webgl2 program not like a webgpu program.
webgl2 version avalible here: https://github.com/BSV-RANDOM/Webgl2_Basic_Fluidsim_Benchmark/tree/main

Note: In order to run webgpu programs generally need to be hosted live. They generally cannot be run locally from html files for security reasons.
